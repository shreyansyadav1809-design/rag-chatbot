# 🤖 AI Chatbot

A simple and intelligent AI chatbot built with **Python, Streamlit, and OpenRouter API**.

The chatbot provides a ChatGPT-style conversational interface with conversation memory and access to free AI models through OpenRouter.

---

## 🚀 Features

- 💬 ChatGPT-style conversational interface
- 🤖 Powered by OpenRouter
- 🆓 Uses free AI models
- 🧠 Conversation memory during the session
- 🗑️ Clear chat functionality
- 🐍 Built with Python
- 🎨 Built with Streamlit
- 🔐 API key stored securely using environment variables / Streamlit secrets
- ⚡ Simple and lightweight architecture
- 💻 Easy to run locally

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **OpenAI Python SDK**
- **OpenRouter API**
- **python-dotenv**
